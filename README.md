# Simulator1PKT

Interaktiv PKT-kristallsimulator av Johannes Wall.

Ladda ned `index.html` och öppna filen i en modern webbläsare. Bilder och programkod ingår i filen; ingen installation behövs.

## Funktioner
- Valfritt heltal som start och hemmatal.
- Klickbar navigering, tillbaka, framåt och spårningshistorik.
- Ändringsbara T-värden, antal T och förskjutning.
- Globala eller lokala villkor, zoom och återställning av vy.

Grundmodell: n = (T + 1)k − 1, T = 4, 6, 8, 12, 20. Visar upp till två steg från centrum. Primtalstestning begränsas till tal under 2⁶⁴. Ändrade parametrar är experiment.

För en publik körbar webblänk: aktivera GitHub Pages under Settings → Pages, med main och /(root).
